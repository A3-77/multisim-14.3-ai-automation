## 1. 题目要求的电路 vs 实际建成的电路

### 1.1 题目原样（circuit_id `c-65aef7c37f`，name `rc_lowpass_p3c`）

| 元件 | family / part | 值 | 位号 |
|---|---|---|---|
| 正弦源 | SIGNAL_VOLTAGE_SOURCES / AC_VOLTAGE | amplitude 1 V, frequency 1000 Hz | V1 |
| 串联臂电阻 | RESISTOR / RESISTOR_VIRTUAL | 1000 Ω | R1 |
| 并联臂电阻 | RESISTOR / RESISTOR_VIRTUAL | 10000 Ω | R2 |
| 并联臂电容 | CAPACITOR / CAPACITOR_VIRTUAL | 1e-8 F | C1 |
| 地 | POWER_SOURCES / GROUND | — | GND1 |

网络（`get_circuit` 回读，与提交完全一致）：

```
in  : V1.1, R1.1
out : R1.2, R2.1, C1.1
0   : V1.2, R2.2, C1.2, GND1.1
```

探针：`P_in` → net `in`；`P_out` → net `out`（都是 V 型电压探针）。

即：V1(1V/1kHz) → R1(1k) → out 节点 → out 对地挂 **R2(10k) ∥ C1(10nF)**。

### 1.2 理论值（自行计算，纯 `cmath`/`math`，未用项目任何模块）

ω = 2π·1000 = 6283.1853 rad/s，|Z_C| = 1/(ωC) = 15915.494 Ω

```
Z_shunt = R2 ∥ (1/jωC) = 10000/(1+j·ω·R2·C) = 8467.330 ∠ -32.1419°  Ω
H = Z_shunt / (R1 + Z_shunt)
```

| 量 | 理论值 |
|---|---|
| \|H\| | **0.907611492** |
| ∠H | **-3.2692°** |
| Vout 幅值（Vin=1V 峰值） | **0.907611 V** |

等价单极点写法（后文用到，是恒等式不是近似）：

```
H = K · 1/(1 + jωτ),  K = R2/(R1+R2) = 0.909090909,
τ = C·(R1∥R2) = 9.0909 µs,  f_p = 17.507 kHz
```

## 2. 仿真结果：失败

`simulate` 调用（circuit `c-65aef7c37f`, analysis `transient`）返回 `ok: false`，耗时 1 ms（连编译都没进）。

**完整报错原文：**

```json
{
  "ok": false,
  "error": {
    "code": "LAYOUT_UNSUPPORTED",
    "message": "网络 'out' 有 2 个到地元件（R2, C1），是并联到地",
    "hint": "P2 每一级最多一个到地元件。两个元件并联到地（比如电阻和电容并联）还没验证过；拆成一个元件，或先用两个电路分别验。",
    "context": {
      "reason": "parallel_shunt",
      "net": "out",
      "shunts": ["R2", "C1"]
    }
  }
}
```

同一判断在 `get_circuit` 的 `topology` 字段里提前出现过一次（未报错，属正常状态提示）：

```json
{"kind": null, "supported": false, "reason": "parallel_shunt",
 "message": "网络 'out' 有 2 个到地元件（R2, C1），是并联到地", ...}
```

`simulate` 的 inputSchema 只有 `circuit_id / analysis / start / stop / sample_rate / timeout`，**没有任何拓扑或布局覆盖开关**，所以没有"绕过"的参数路径。

## 3. 判断：后端能力边界，不是电路错、也不是参数错

依据：

1. **电路本身电学合法**。R2 与 C1 并联到地是教科书式一阶 RC 低通 + 直流泄放通路，无悬空节点、无短路、无源短路、有唯一参考地、有直流通路。SPICE 层面完全可解，理论值 0.907611 V 有闭式解。
2. **报错阶段是布局，不是仿真**。`error.code = LAYOUT_UNSUPPORTED`、`context.reason = parallel_shunt`，且总耗时 **1 ms**——编译（正常 ~15–17 s）和 Multisim 运行都没开始。说明后端在"把电路摆成原理图"这一步就拒绝了，问题在**拓扑表达能力**，不在数值/收敛。
3. **错的是"每级最多一个到地元件"这条布局规则**，`hint` 自己承认"两个元件并联到地……还没验证过"。这是能力边界（未验证组合），不是"这样接是错的"。
4. **参数无误**：报错里点名的是 R2、C1 两个元件的**存在**，不是它们的数值。`rlc_reported_by_multisim` 在能跑的电路里回读 R1=1000.0、R2=10000.0，与提交一致。

结论：**题目电路没有任何错误，是执行器的布局引擎只支持"每级单 shunt"，无法表达 shunt 并联支路。** 属于工具能力边界。

> 补充（非借口）：这不影响题目本身成立。任何真实 SPICE 都能跑这个电路；是执行器的拓扑模板（divider / bypass / ladder / tee…）里没有 `R∥C` 这一档。

## 4. 替代方案与实测数据

思路：把 `H = K · 1/(1+jω·(R1∥R2)·C)` 这个**恒等式**拆成两个各自可仿真的单 shunt 电路，分别实测 `K` 和极点因子，再相乘还原复合增益。拆的是"布局"，不是"题目"——元件值、拓扑关系一个没改。

| 编号 | circuit_id | 电路 | 验证目标 |
|---|---|---|---|
| A | `c-81c5564135` | V1 → R1(1k) → out，out 对地 R2(10k) | K = R2/(R1+R2) |
| B | `c-de0d8b09ea` | V1 → R1(1k) → out，out 对地 C1(10nF) | 1/(1+jωR1C)（验证 C=10nF 真实生效） |
| C | `c-c0b755640f` | V1 → R1(909.0909Ω) → out，out 对地 C1(10nF) | 1/(1+jω(R1∥R2)C)（极点因子） |

### 4.2 复合增益还原（A × C）

```
H_measured = 0.909090908 × 0.998362653 = 0.907602411  ∠ -3.2798°
H_theory                              = 0.907611492  ∠ -3.2692°
幅值相对误差 = 1.00e-5  (-0.0010 %)
相位绝对误差 = 0.011°
```

**输出节点实际幅值：**

| 口径 | 数值 |
|---|---|
| 归一化到 1V 输入（推荐，抵消源幅度偏差） | **0.907602 V** |
| 按实测源幅度 0.9967953 V 折算 | **0.904694 V** |
| 理论（1V 输入） | 0.907611 V |

误差：归一化口径 **-0.0010 %**；用实测源幅度口径 **-0.3215 %**。

### 4.3 一个必须说清楚的观测：源幅度不是 1.0000

三个电路里 `P_in` 的正弦拟合幅值都是 **0.99679**，而 `value` 提交的是 1.0（`source_amp: 1.0`）。

- A 的输入负载 11 kΩ，B/C 的输入负载约 1 kΩ，**负载差 10 倍，源幅度一模一样**（0.9967958 / 0.9967942 / 0.9967953），所以**不是**源内阻分压，而是源本身被写成/量化成 0.9968 这个电平（恒定 0.32% 标度）。
- 因此**绝对幅值不可直接与 1V 理论对比**，而 `measure` 的 `gain`（ratio 模式，`P_out/P_in`）把这个常数因子约掉了，是可信量。上表主结论用 ratio。

## 6. 结论

- **题目电路建成了，但跑不了**：`out` 节点上 R2 ∥ C1 两个到地元件，被布局引擎以 `parallel_shunt` 拒绝，报错发生在布局阶段（1 ms，未编译、未启 Multisim）。
- **这是工具能力边界，不是电路/参数错误**。电路电学合法、理论有闭式解 0.907611 V；后端 `hint` 自认"两个元件并联到地还没验证过"，且无任何参数可绕过。
- **可实际验证的替代方案给出了实测**：分压 + 极点两段实测，还原复合增益 **0.907602 ∠ -3.280°**，理论 **0.907611 ∠ -3.269°**，幅值相对误差 **1.0e-5（-0.0010%）**，相位差 **0.011°**。三个子电路的单体误差分别在 1e-9、1e-5 量级，说明 R1/R2/C1 的阻容值在 Multisim 里确实按提交值生效。
- 需要提醒的边界：0.907602 是**由两个实测子结果按精确恒等式合成**的，不是对 `R∥C` 网络的一次直接瞬态测量。要直接测它，需要后端支持"每级多 shunt"（并联支路）。
