# Agent Acceptance Test #2 —— 二阶 / 多节点电路

> 测试者：外部使用者 Agent（只读 MCP `tools/list`，不知道 Multisim 任何内部概念）
> 被测对象：`multisim-circuit` MCP Server
> 约束：全程只走 MCP 协议，未 import 项目模块、未调 `msbuild`、未构造 Circuit IR、未碰 `.ms14`
> 时间：2026-10-26

---

## 任务（没给任何设计思路，只给指标）

> 设计一个 1kHz 正弦输入经过二阶低通滤波器，截止频率约 2kHz，
> 要求输出幅值和理论值进行验证。

---

## 我的设计决策

二阶 RC 梯形低通，两节取相同值（`R1=R2=R`、`C1=C2=C`），传函：

```
H(s) = 1 / (1 + 3·sRC + (sRC)²)
fc   = 1 / (2πRC) = 2 kHz   ->   RC = 79.6 µs
```

取 E12 标准值：

| | 值 | fc |
| --- | --- | --- |
| R | 10 kΩ | |
| C | 8.2 nF | **1940.9 Hz**（目标 2 kHz，−2.95%，设计选择） |

1 kHz 处理论值：`|H| = 0.58434`、`∠H = −64.58°`、`Vout = 0.58434 V`。

# 第一轮（v0.6.2）：电路建成了，仿真被拒

### 1. 建电路：16 次调用，零错误

| 步骤 | 调用 | 结果 |
| --- | --- | --- |
| 1–2 | `initialize` / `tools/list` | 8 个工具都在，含新增的 `get_circuit` |
| 3 | `create_circuit` | `c-...` |
| 4–9 | `add_component` × 6 | V1 / R1 / C1 / R2 / C2 / GND1 |
| 10–13 | `connect` × 4 | 见下面拓扑 |
| 14–15 | `add_probe` × 2 | P1→`in`、P2→`n2` |
| 16 | `get_circuit` | 6 元件 / 4 网络 / 2 探针，`warnings: []` |
| **17** | **`simulate`** | **`LAYOUT_UNSUPPORTED`** |

`get_circuit` 读回来的拓扑完全正确：

```
in  ['V1.1', 'R1.1']
n1  ['R1.2', 'C1.1', 'R2.1']        <- 三引脚节点（分流支路）
n2  ['R2.2', 'C2.1']                <- 输出
0   ['C1.2', 'C2.2', 'V1.2', 'GND1.1']
```

**这是一张教科书式的二阶 RC 梯形网络**，`warnings` 是空的 —— 电路本身没有任何问题。

### 2. 仿真被拒，错误信息很清楚

```json
{
  "code": "LAYOUT_UNSUPPORTED",
  "message": "网络 'n1' 有 2 个分支（C1.1, R2.1）",
  "hint": "第一版只支持串联链；并联 / 多支路的布局还没验证过。",
  "context": {"net": "n1", "branches": ["C1.1", "R2.1"]}
}
```

它准确指出了**哪条网络、哪个引脚分叉**。我没有猜、没有重试十次 ——
一看就知道这不是我连错了，是后端不支持这种拓扑。

### 3. 这一轮真正证明了什么

| 层 | 结论 | 证据 |
| --- | --- | --- |
| **MCP 语义层（API）** | ✅ **够用** | 6 个元件、4 条网络（含三引脚节点和四引脚地网）、2 个探针，全部用语义参数建出来，16 次调用零错误，`warnings: []` |
| **后端布局层（P2）** | ❌ **挡住** | `plan_layout()` 只认单链、`MAX_PASSIVES = 2` |

> **表达层成立了**（Agent 能把多节点电路准确描述出来，一次就对）；
> **执行层还没跟上**（布局只覆盖单链）。

第 16 步 `get_circuit` 是这一轮最有价值的一步：**它把"我的电路对不对"和
"后端能不能跑"分开了。** 没有它，`LAYOUT_UNSUPPORTED` 会让我怀疑自己。

# 第二轮（v0.7.0）：同一个脚本，跑出数了

### 5. 实测 vs 理论

| 项 | 实测 | 理论 | 误差 |
| --- | --- | --- | --- |
| R1 / R2 | 10 kΩ / 10 kΩ | — | E12 标准值 |
| C1 / C2 | 8.2 nF / 8.2 nF | — | E12 标准值 |
| fc | 1940.914 Hz | 目标 2000 Hz | −2.95%（设计偏差，不是仿真误差） |
| 输入幅值 | 0.996794 V | 1.000000 V | −0.32% |
| 输出幅值 | 0.581193 V | 0.584342 V | — |
| **增益** | **0.583062** | **0.584342** | **−0.219 %** |
| **相位** | **−64.705°** | **−64.581°** | **−0.123°** |

理论模型是二阶 RC 梯形（不是两级隔离缓冲）：

```
H(s) = 1 / (s²R1R2C1C2 + s(R1C1 + R2C2 + R1C2) + 1)
```

### 6. 后端这次自己说出了它理解的拓扑

`get_circuit` 和 `simulate` 的返回里都带 `topology`（v0.7.0 新增）：

```json
{"kind": "ladder", "source": "V1", "ground": "GND1",
 "in_net": "in", "gnd_net": "0", "out_net": "n2",
 "n_series": 2, "n_shunt": 2,
 "stages": [
   {"index": 0, "net": "in", "series": "R1", "shunt": null},
   {"index": 1, "net": "n1", "series": "R2", "shunt": "C1"},
   {"index": 2, "net": "n2", "series": null, "shunt": "C2"}],
 "supported": true}
```

三引脚节点 `n1` 现在是**正常的一级**，不再是异常。我不用再猜后端怎么理解
我的电路 —— 这一点对 Agent 很重要：第一轮我只能靠 `LAYOUT_UNSUPPORTED`
反推，这一轮我可以提前看到。

## 还剩什么

1. **真正的并联支路 / 并联到地 / 反馈 / 桥接**：v0.7.0 是明确拒绝
   （`fork` / `parallel_shunt`），不是排不出来。网表本来就能表达，
   缺的是"两条并排支路怎么摆才看得懂，且不穿符号"。
2. **主干 > 4 级、多电源**：同上，明确拒绝。
3. **`GetCircuitImage` 画不出我们生成的 V1/C1**（第一轮验收的问题 8）：
   与仿真无关，单独开任务。

按用户定的路线，P2 通过之后才考虑接 LLM。现在 P2 通过了，
**下一个就是 LLM → MCP**。
