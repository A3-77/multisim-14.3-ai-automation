## P2 —— 并联 / 多支路：把 `LAYOUT_UNSUPPORTED` 变成能用

### 为什么这是下一个

MCP 第一版只支持单电源串联链到地。并联不是"没实现"，是**明确拒绝**：

```json
{"code": "LAYOUT_UNSUPPORTED",
 "message": "网络 'in' 有 2 个分支（R1.1, R2.1）",
 "hint": "第一版只支持串联链；并联 / 多支路的布局还没验证过。"}
```

这个错误现在每次建分压器都会撞到。所以下一个该解决它。

### 已知事实

- v0.2.0 已经**证伪**"必须有 junction 结点对象"：3 引脚中点不需要任何结点，
  实测读到 2.5 V（`docs/deadends.md`）。所以底层能力不缺。
- IR 的 `nets` 本来就是"网络 → 引脚列表"，能表达任意拓扑。
- 缺的只有**布局**：`circuit_session.plan_layout()` 现在只会排一条链。

### 做什么

1. 写一个真正的布局器，替换现在的 `plan_layout()`：
   - 找电源 → 放左；找地 → 放底部
   - 其余元件按"离电源网表的层数"分层，同层纵向排开
   - 元件朝向（旋转）还没验证过，可能要先只支持水平/垂直两种
2. 保留"拓扑不认识就报错"的原则：先只加**三个固定模板**（分压、旁路电容、T 型），
   模板之外仍然 `LAYOUT_UNSUPPORTED`。
3. `nl2ir` 加"并联 / 并在...两端 / 和...并联"的句式。

### 怎么算完成

分压器 + 旁路电容（`R1/R2/C1`）用 MCP 建出来，Multisim 里中点电压对上
`R2/(R1+R2)`，交流下旁路电容让增益随频率下降。

## P3 —— 元件库扩容

### 问题

现在只能克隆"样例库里出现过"的 `(family, part)`。多引脚元件（运放、555）
的引脚重映射还没验证过，`add_part` 目前只对 2 引脚 + 地做过验收。

### 方向

1. 从 `corpus/samples_index.json` 挑一个运放样例，跑通 `add_part` 的多引脚路径
   （重点：`PortID` 重映射、引脚名是否唯一）。
2. 建 `templates/` 目录，把每种用到的元件子树存成模板，摆脱"必须找到 donor 文件"。
3. 单位哈希表：`&UNI<值>_uc<hash>` 的 hash 算法未知，现在是"继承旧值后缀"绕过的。
4. 探针 > 9：`LocalName` 序号超过一位数字时的命名规则需要先确认。

## P4 —— LLM 外壳（放在最后，不要提前做）

现在有**两条**入口，都产出同一份 Circuit IR：

```
自由中文 ──► nl2ir ──┐
                     ├──► Circuit IR ──► msbuild ──► .ms14 ──► Multisim
Agent ──► MCP ───────┘
```

LLM 的正确位置是**最上面**，且只做"规范化"：

```
自由中文
  ↓  LLM：只把口语说法规范化成受控句式，不产出 IR
受控句式（"1V 1kHz 正弦源，经过 1kΩ 电阻后接 159nF 电容到地，..."）
  ↓  nl2ir（确定性、可测试）
Circuit IR
```

失败时把 `NLParseError.issues` 或 MCP 的 `error.hint` 回灌给模型让它重写。
**不要让 LLM 直接写 IR**，否则"同一句话两次生成不同电路"会一直跟着你。

### 真正值得试的第一个测试

不是"能不能画 RC"，而是：

> **"帮我设计一个 1kHz 的 RC 低通，输入 1V，截止频率 500Hz，仿真后告诉我输出幅值。"**

这句话里没有元件值 —— Agent 得自己算出 `R` 和 `C`（`fc=500Hz` 有无穷多组解，
需要它选一组），然后调 MCP 建电路、跑、读、解释。
**如果这一步能过，就说明整条路线成立了。**
