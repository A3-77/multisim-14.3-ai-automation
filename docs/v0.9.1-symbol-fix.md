# v0.9.1 · 符号不渲染的根因与修复

**状态：已修复并实测验证。**

一句话：`Assembler.add()` 在平移元件时，把 **symbol 根节点**
（`CIITSymbolComp` 本身）的 `Transformer-M20/M21` 也加了偏移。
Multisim 渲染时会把根变换**再叠加一次**到子对象上，符号因此被推出画布。
CiNode/CiPort 拓扑与 SPICE 网表完全正确，所以仿真照跑、只有图形坏掉。

---

## 1. 症状

生成的 `.ms14` 在 Multisim 14.3.3 里打开：

- 能仿真，波形与理论一致；
- 但画布上 **V1 / C1 / GND 符号完全不可见**；
- R1 符号错位到导线下方很远处；
- 探针正常显示，导线正常连接。

`GetCircuitImage` 导出与 GUI 窗口截图表现一致，所以不是渲染器差异。

## 3. 根因（数值证据）

取同一个元件 R1，对比 **donor 原件** 与 **我们生成的文件**：

| | 根 `CIITSymbolComp` M20/M21 | 子对象 `CIITSymTextCompName` |
|---|---|---|
| donor（`Amplificador para resistencia de 1mOhm.ms14`） | (0, −18) | (502, 106) |
| 我们生成 | (5, 151.5) | (507, 275.5) |

**两者平移量完全相同：根 (5, 169.5)、子对象 (5, 169.5)。**

关键在这里：donor 里根是 (0, −18)，几乎就是单位矩阵；我们平移时
「遍历 symbol 里所有带 `Transformer-M20/M21` 的元素，统一加 dx/dy」——
根也被加了，于是根变成了 (5, 151.5)。

而 Multisim 的渲染语义是：

```
最终位置 = 根变换 ∘ 子对象变换
```

子对象存的是**图纸绝对坐标**，不是相对根的偏移。所以根一旦带上平移，
就等于把整个符号再推一次。GROUND 的 donor 根是 **(270, 450)**，
一叠加直接把符号送出图纸，这就是「符号全丢」的来源。

### 为什么以前没被发现

- RESISTOR 的根只有 (0, −18)，偏移 18 单位在 960px 的导出图里几乎看不出来；
- GROUND 的根是 (270, 450)，但地符号小、又常被导线覆盖，容易被当成「没画」；
- 仿真路径（CiNode → CiPort → SPICE 端子）完全不经过 symbol 变换，
  所以「网表对、仿真对、图形错」能长期共存。

## 4. 修复

两处，都只改「平移时怎么处理根」：

### `tools/msbuild.py` · `Assembler.add()`

```python
sym_root = list(sym)[0] if len(sym) else None
for el in sym.iter():
    if el.tag == "CIITPinConnectorComp":
        continue
    px, py = el.get("Transformer-M20"), el.get("Transformer-M21")
    if px is None or py is None:
        continue
    if el is sym_root:                 # 根必须保持单位矩阵
        el.set("Transformer-M20", "0.")
        el.set("Transformer-M21", "0.")
        continue
    el.set("Transformer-M20", "%g." % (_f(px) + dx))
    el.set("Transformer-M21", "%g." % (_f(py) + dy))
```

### `tools/msmodel.py` · `Circuit.translate()`

同一处理：根节点归零，不参与平移。

### 为什么归零是安全的

对 6 个 enabled 元件逐个检查 donor symbol 根的 2×2 线性部分
（原始数据：`docs/evidence/v0.9.1-symbol/06_donor_roots.json`）：

```
CAPACITOR/CAPACITOR_VIRTUAL        M00=1 M01=0 M10=0 M11=1  M20=-36  M21=9
DIODE/1N4007G                      M00=1 M01=0 M10=0 M11=1  M20=-9   M21=-27
POWER_SOURCES/DC_POWER             M00=1 M01=0 M10=0 M11=1  M20=693  M21=144
POWER_SOURCES/GROUND               M00=1 M01=0 M10=0 M11=1  M20=270  M21=450
RESISTOR/RESISTOR_VIRTUAL          M00=1 M01=0 M10=0 M11=1  M20=0    M21=-18
SIGNAL_VOLTAGE_SOURCES/AC_VOLTAGE  M00=1 M01=0 M10=0 M11=1  M20=297  M21=288
```

**全部是单位矩阵**，只有平移非零。归零不影响朝向/镜像/缩放。
